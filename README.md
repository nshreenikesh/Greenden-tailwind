# 🛍️ Product Website

I have created a simple and responsive **Product Website** using **HTML** and **Tailwind CSS**.  
This project includes the following pages:

- 🏠 **Product Page** – Showcases the products with a clean and modern layout.  
- 📞 **Contact Page** – Allows users to get in touch easily through a contact form.

## 🧰 Technologies Used
- HTML5  
- Tailwind CSS  

## ✨ Features
- Responsive design for all devices 📱💻  
- Clean UI with Tailwind styling  
- Easy navigation between pages  
- Lightweight and fast-loading

## 🚀 How to View
1. Download or clone this repository.  
2. Open `index.html` in your browser to view the product page.  
3. Navigate to `contact.html` to access the contact form.
